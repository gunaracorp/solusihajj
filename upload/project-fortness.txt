└── /robots.txt                    Crawl rules
```

## 2. ATURAN PENAMAAN URL (SLUG)

- Bahasa Indonesia, huruf kecil, hubungkan dengan tanda minus
- Max 5 kata, keyword di depan (contoh: `sertifikasi-halal` ✅, `layanan-jasa-sertifikasi-halal-terbaik` ❌)
- TANGA datar — maksimal 2 level (`/layanan/sertifikasi-halal/`), tidak boleh lebih dalam
- Slug artikel: topik + tahun bila relevan (`cara-daftar-halal-self-declare-2025`)

## 3. NAVIGASI HEADER

```
[LOGO TopKonsultan]  Beranda | Tentang | Layanan ▾ | Artikel | FAQ | Kontak   [Konsultasi Gratis →]
                                      ├── Legalitas Usaha
                                      ├── Sertifikasi Halal ⭐ (hot!)
                                      ├── Sertifikasi Produk & Sistem
                                      ├── Paket Siap Ekspor
                                      ├── PT PMA & Investasi Asing
                                      └── Perizinan Sektor Khusus
```
- Mobile: hamburger → drawer slide-in, CTA "Konsultasi Gratis" TETAP tampil
- Dropdown desktop: hover + keyboard accessible

## 4. NAVIGASI FOOTER (3 Kolom + NAP)

```
KOLOM 1: PERUSAHAAN          KOLOM 2: LAYANAN          KOLOM 3: KONTAK
- Tentang Kami               - 6 link layanan           - Alamat kantor lengkap
- Artikel                    - FAQ                      - WA: +62xxx (klik)
- FAQ                        - (P3 di-highlight)        - Email: halo@topkonsultan.web.id
- Kontak                                                - Jam operasional
                                                        - Google Maps link
[Legal Line] © 2025 PT Top Konsultan Internasional — Terdaftar [no. PT] | Kebijakan Privasi (v1.1)
```
Footer = NAP (Name-Address-Phone) KONSISTEN dengan Google Business Profile — penting untuk local SEO.

## 5. BREADCRUMB (tampil di semua halaman kecuali homepage)

```
Beranda › Layanan › Sertifikasi Halal
```
Pakai schema BreadcrumbList agar muncul di hasil pencarian Google.

## 6. PETA INTERNAL LINKING (Strategi)

```
Artikel SEO ──(link anchor relevan)──► Halaman Layanan ──► Kontak/WA
     ▲                                      │
     └────── (link terkait antar artikel) ──┘
```
ATURAN:
1. Setiap artikel WAJIB link ke minimal 1 halaman layanan (ini ujung tombak konversi)
2. Setiap halaman layanan link ke 2–3 artikel pendukung (menambah waktu di site)
3. Homepage link ke semua 6 layanan (distribute authority)
4. Anchor text deskriptif ("jasa sertifikasi halal BPJPH" ✅, "klik di sini" ❌)
```

| Kriteria (bobot) | HTML+Tailwind | WordPress | Astro | Next.js | PHP Native |
|------------------|:---:|:---:|:---:|:---:|:---:|
| Shared hosting compatibility (25%) | ✅ 10 | 8 | 7* | 4 | 9 |

| Keamanan attack surface (15%) | 10 | 5 | 8 | 7 | 6 |

| Biaya (10%) | 10 | 7 | 9 | 6 | 9 |
| Butuh SDM khusus (10%) | 10 | 6 | 7 | 5 | 7 |
| Skalabilitas konten blog (5%) | 6 | 10 | 9 | 9 | 7 |
| **TOTAL** | **9.65** | **6.6** | **7.85** | **6.0** | **7.35** |

*Astro butuh build step — sama seperti pilihan kita, tapi menambah 
abstraksi yang tidak diperlukan untuk 14 halaman.
WordPress kalah: target hack terbesar dunia, butuh maintenance rutin 
(plugin update), performa biasa-biasa saja untuk shared hosting.
Next.js kalah: butuh Node runtime/adapter — shared hosting tidak support.

## 3. CATATAN KRITIS: TAILWAP CDN DILARANG DI PRODUCTION

❌ `<script src="https://cdn.tailwindcss.com">` — JANGAN dipakai untuk live
Alasan: JS runtime besar (menyedot skor performa), tidak ada purging.
✅ Cara benar — Tailwind CLI standalone:
```bash
# Download tailwindcss standalone binary (sekali)
# Struktur project:
project-fortress/
├── src/
│   ├── input.css        (@tailwind base/components/utilities)
│   ├── pages/*.html
│   └── assets/ (img, js)
├── dist/                (hasil build — INI yang diupload)
└── docs/
```
```bash
# Build command (jalankan tiap ada perubahan):
./tailwindcss -i src/input.css -o dist/assets/css/style.css --minify
```
Hasil: SATU file CSS ~15–25KB (purged) = performa maksimal.
