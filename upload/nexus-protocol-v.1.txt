## FASE 9️⃣ — DEPLOYMENT KE SHARED HOSTING (Hari 14–15)

**Pilihan A — via Git (hosting yang support):**
```bash
# Di cPanel → Setup Git → clone repo → set deploy branch
```

**Pilihan B — Manual (paling universal):**
```bash
# Build lokal → compress → upload via File Manager/FTP → extract ke public_html
# Pastikan: index.php/index.html ada di root public_html
# Aktifkan SSL: cPanel → SSL/TLS → AutoSSL/Let's Encrypt → Force HTTPS
```

**Pilihan C — FTP via GitHub Actions (PRO move!):**
```yaml
# .github/workflows/deploy.yml
name: Deploy ke Hosting
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Upload via FTP
        uses: SamKirkland/FTP-Deploy-Action@v4.3.4
        with:
          server: ${{ secrets.FTP_SERVER }}
          username: ${{ secrets.FTP_USER }}
          password: ${{ secrets.FTP_PASSWORD }}
          local-dir: ./public/
```
> Dengan ini: **push ke GitHub = auto-deploy**. Klien terkesan, kamu hemat waktu. 🔥

## FASE 🔟 — HANDOVER & MAINTENANCE (Hari 15+)

# 🐙 BAGIAN 4: STANDARISASI GITHUB

## Struktur Branch
```
main        → kode production (yang online)
dev         → kode stabil terbaru  
feature/nama-fitur  → pengerjaan fitur baru
hotfix/deskripsi    → perbaikan darurat
```

## Format Commit Message (Conventional Commits)
```
feat: tambah halaman about dengan animasi scroll
fix: perbaiki form contact tidak terkirim di Safari
docs: update design system font scale
style: sesuaikan warna button dengan brand guideline
refactor: pisahkan komponen hero ke file sendiri
```

## File Wajib di Root Repository
| File | Fungsi |
|------|--------|
| `README.md` | Deskripsi project, cara setup, link dokumen |
| `.gitignore` | Kecualikan node_modules, .env, file rahasia |
| `LICENSE` | Perlindungan karya (MIT untuk milikmu, proprietary untuk klien) |
| `CONTRIBUTING.md` | Aturan kalau ada kolaborator |

> ⚠️ **KEAMANAN:** JANGAN PERNAH commit password hosting, API key, .env. Gunakan GitHub Secrets.

# 🛡️ BAGIAN 5: STANDARISASI SHARED HOSTING

## Checklist Kelayakan Hosting (untuk rekomendasi klien)
```
□ PHP 8.1+ support          □ SSL gratis (Let's Encrypt)
□ SSD storage                □ Bandwidth cukup / unmetered
□ Backup otomatis mingguan   □ cPanel (standar industri)
□ Uptime 99.9% guarantee     □ Support responsif (WA/ticket)
```

## Keamanan Wajib Pasca-Deploy
1. ✅ Force HTTPS semua halaman
2. ✅ Hapus file installer/cache sementara
3. ✅ Set permission folder 755, file 644
4. ✅ Disable directory listing (.htaccess: `Options -Indexes`)
5. ✅ Tambah security headers di `.htaccess`:
```apache
<IfModule mod_headers.c>
  Header set X-Content-Type-Options "nosniff"
  Header set X-Frame-Options "SAMEORIGIN"
  Header set X-XSS-Protection "1; mode=block"
  Header set Referrer-Policy "strict-origin-when-cross-origin"
</IfModule>
```
